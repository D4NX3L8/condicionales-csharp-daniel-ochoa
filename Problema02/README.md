# Problema 02. Tarifa de envío por peso

**Estructura elegida:** if / else if.

**Justificación:** Los límites de peso definen rangos ordenados y requieren rechazar valores no positivos.

## Evidencia

La salida de la ejecución de prueba en terminal se guarda en [evidencias/salida.txt](evidencias/salida.txt).

## Ejecución

```bash
dotnet run --project Problema02.csproj
```

Los datos se ingresan por líneas en el orden solicitado por el ejercicio.
