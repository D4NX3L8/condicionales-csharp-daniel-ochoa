# Problema 21. Carrito de compras

**Estructura elegida:** operador ternario.

**Justificación:** Solo el valor uno cambia el sustantivo; los demás usan el plural.

## Evidencia

La salida de la ejecución de prueba en terminal se guarda en [evidencias/salida.txt](evidencias/salida.txt).

```bash
dotnet run --project Problema21.csproj
```
