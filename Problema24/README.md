# Problema 24. ¿Día hábil?

**Estructura elegida:** expresión `switch` con patrones relacionales.
**Justificación:** Los días hábiles forman un rango consecutivo (1 a 5), los días 6 y 7 son fin de semana y cualquier otro número queda clasificado como inválido.

La captura de este ejercicio se agregará posteriormente a la carpeta de evidencias.

## Ejecución

```bash
dotnet run --project Problema24.csproj
```

El número del día se ingresa por consola.
