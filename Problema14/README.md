# Problema 14. Estado del aprendiz

**Estructura elegida:** operador ternario.

**Justificación:** La nota produce uno de dos estados y se asigna en una sola línea.

## Evidencia

La salida de la ejecución de prueba en terminal se guarda en [evidencias/salida.txt](evidencias/salida.txt).

```bash
dotnet run --project Problema14.csproj
```
