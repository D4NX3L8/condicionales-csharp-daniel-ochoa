# Problema 27. Taquilla de cine

**Estructura elegida:** expresiones `switch` anidadas con una condición ternaria.
**Justificación:** El día determina primero si el precio es fijo (martes o fin de semana) o si depende de la condición de estudiante (lunes a viernes, excepto martes). Las entradas de día y respuesta se normalizan para aceptar mayúsculas y variantes sin tilde.
