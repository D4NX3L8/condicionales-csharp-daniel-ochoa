# Problema 20. Días de cada mes

**Estructura elegida:** switch con casos agrupados.

**Justificación:** Varios meses comparten duración y se agrupan en las mismas ramas.

## Evidencia

La salida de la ejecución de prueba en terminal se guarda en [evidencias/salida.txt](evidencias/salida.txt).

## Ejecución

```bash
dotnet run --project Problema20.csproj
```

Los datos se ingresan por líneas en el orden solicitado por el ejercicio.
